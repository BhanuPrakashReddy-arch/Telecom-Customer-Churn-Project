# Telecom Customer Churn Prediction

## Project Overview
This project predicts customer churn and revenue forecasting using Machine Learning techniques also provides business recommendations based on model insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
- SHAP
- Google Colab

## Project Tasks
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Classification Models
- Regression Models
- SHAP Analysis
- PDP Analysis
- Business Recommendations
- ROI Analysis
